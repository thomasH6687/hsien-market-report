二、這和最近幾天最大的差別

舊主流退、新主流補位的模式，今天第一次失效。

三、HBM：最近最重要的強勢錨，今天正式 Reset

HBM 收盤 -3.6%、0/7 上漲，成交約 1,604 億，資金占比 13.7%，相較昨日 +4.2。高資金占比搭配 -3.6% 與 0/7，比較像大量換手、賣壓釋放與承接測試，不是新的多頭流入。

11:05 -3.3% → 12:15 -3.6% → 收盤 -3.6%，完全沒有收回。

🔻 HBM：Leadership → Reset

Memory Selective Strength 正式被打斷，不能再沿用上週「HBM／記憶體比較抗跌，所以逢回承接」的判斷。

手機鏡頭收盤 +2.93%、大戶 +18.00、流動大戶 +16.13；11:05 一度 +3.89%、流動大戶 +48.56。動能雖下降，但大盤 -1.8% 時仍收 +2.9%。車用鏡頭午盤一度很強，尾盤分化，整個光學鏈仍是今日最強電子相對強勢。

十三、最重要的市場風格變化

前幾天是 Offensive Rotation：PCB → AI → 被動元件 → 記憶體 → 光學。今天是 Defensive Rotation：光學＋塑化＋航運＋金融＋電信＋低 Beta 傳產。

前者有利提高總曝險；後者通常是在保護資本。

十八、明天 10/14 先看 Breadth Repair

明天的重點不是找誰反彈最多，而是判斷今天是一日去槓桿，還是市場 Regime 真正改變。今天加權廣度 -42.8%、櫃買 -52.5%；若開盤後快速回到 -10%～0% 甚至轉正，較可能是大型洗盤後修復。若仍是 -30%、-40%，就不是一次性洗盤。

十九、近期 Leader 能否快速回來

優先觀察 HBM、PCB、先進封裝與 CPO。不是要求立刻大漲，而是停止創低、廣度改善、資金不再負向擴散。HBM 若由 0/7 回到 4/7 很有資訊價值；若仍只有 0/7、1/7，Reset 尚未完成。

二十、今天的逆勢強者能否留下來

觀察手機／光學鏡頭、貨櫃、塑化與金融。若市場反彈時仍保持強勢，可能成為下一輪新 Leadership；若市場一反彈就被賣，今天只是臨時避風港。

二十一、操作策略與市場燈號

只留有證據的部位：真正相對強勢、技術面沒有破壞、有利潤墊、籌碼未明顯轉壞。若族群結構壞、個股破重要支撐、大戶轉負且沒有利潤保護，就依原定策略處理。

🔴 10/13 收盤市場操作燈號：紅燈

收盤市場廣度仍極弱，原本多條 Leadership 同時結構性破壞，Broad Risk-Off、Leadership Breakdown、Defensive Rotation 三者同時成立。

10/05～10/12：輪動在支撐市場。
10/13：輪動不足以支撐整個市場。
接下來：先確認市場能否修復，再決定是否把現金重新轉回股票。

後續判斷優先級改為 Breadth Repair（市場廣度修復）＞ 新族群排名；市場重新證明修復能力前，不把任何單一族群的逆勢上漲解讀成市場恢復正常。

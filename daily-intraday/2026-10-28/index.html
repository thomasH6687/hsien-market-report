✅ 二次確認 OK

今天收盤資料把上午最後一個疑問解掉了。全日正式定義為：

🟢 Risk-on Confirmation Day｜風險偏好重新擴張確認日

這不是單純跌深反彈，也不是只有權值拉指數。今天最漂亮的不是加權上漲 2.0%，而是尾盤結構比中午更強；市場已由輪動轉為主線共振，但量能尚未同步擴張，因此新的波段主升仍需隔日 Follow-through。

  1. 加權維持 +1.3% 以上，收盤 +2.0%。
  2. 櫃買維持 +3% 以上，收盤 +4.1%。
  3. 市場廣度維持明顯正值，收盤為 +39.6%／+41.9%。

因此今天的確認度已由「偏高」升級為 高。

二、最關鍵的是尾盤再擴張

12:45 到收盤，上市淨廣度由 +32.5% 提高到 +39.6%，櫃買淨廣度由 +34.7% 提高到 +41.9%；加權由 +1.7% 提高到 +2.0%，櫃買由 +3.6% 提高到 +4.1%。

加權最高 47,060.46、收 47,035.58，幾乎收在最高附近；櫃買最高 394.61、收盤同為 394.61，直接收最高。

這不是典型的「早盤嘎空、中午鈍化、尾盤獲利了結」，而是：

早盤強 → 中午整理 → 尾盤重新擴散。

尾盤價格與廣度同步墊高，使今天的 Risk-on 訊號可信度明顯提高。

三、ASIC／矽智財：第一梯隊新核心

客製 ASIC 收盤 +7.2%、8/8 全數上漲；XQ 的設計 IP 約 +6.63%，矽智財相關也在約 +7% 級。

資金不是只買 GPU 相關舊題材，而是往 Custom ASIC＋IP 延伸。這代表 AI 資本支出鏈的設計端與運算端開始共振，ASIC／矽智財正式進入第一梯隊。

四、記憶體：由 HBM 支線擴大為全面化

記憶體模組收盤 +5.2%、14/14；NOR Flash +4.5%、9/9。XQ 同時顯示利基型記憶體 +7.03%、記憶體模組 +5.44%、記憶體製造 +4.72%；另一組資料顯示利基型記憶體 +7.80%、DRAM +5.81%。

今天的結構已不只是 HBM 單一支線，而是：

HBM → DRAM → NOR → 模組 → 利基型記憶體

族群全面化通常比單一龍頭漲停更健康，記憶體因此升格為第一梯隊主線之一。

五、PCB：完整族群攻擊

PCB 硬板收盤 +4.8%、21/21 全數上漲；路徑由早盤 19/21、10:35 的 19/21，提高到 12:45 與收盤的 21/21，成交額約 974.9 億元。

這不能再只稱為跌深反彈，而是完整族群攻擊。PCB 今日正式回到第一線主線，且廣度在尾盤沒有縮小，反而完成全數上漲。

六、封裝／設備：半導體整條鏈共振

封裝量測自動化 +5.1%、12/12；前段製程設備 +5.1%、4/4。XQ 顯示先進封測 +4.91%、半導體封測材料 +5.35%、IC 載板 +4.63%、IC 測試 +4.04%。

今天不是晶圓代工單點反彈，而是：

設計 → 製造 → 封裝 → 測試 → 材料 → 載板

整條鏈同時上漲，是今日最重要的主線共振證據之一。

七、CXL／CPO沒有掉隊

CXL 收盤 +4.7%、8/8；矽光子／CPO 仍位於強勢群。AI 產業鏈已形成較完整的資金結構：

  1. ASIC／矽智財
  2. 晶圓代工
  3. HBM／Memory
  4. 先進封裝／測試
  5. PCB／載板
  6. CXL／CPO

前幾日的特徵是快速 Rotation；今天則開始出現 Rotation → Convergence，資金輪動逐漸收斂成共同主線，市場品質明顯改善。

八、Risk-on Rotation：賣防禦、買科技成長

跌幅前段主要是 NIKE 運動鞋 -1.40%、板鋼 -1.39%、工業用紙 -1.13%、肉品 -1.13%、輪胎 -0.84%、房地產 -0.80%、金控 -0.64%、天然氣 -0.63%。

資金不是全部一起漲，而是明確由防禦、傳產與低 Beta 轉向科技、成長與 AI。這種資金遷移比全面普漲更有資訊價值，符合標準的 Risk-on Rotation。

九、唯一沒有完全確認的是量

加權成交約 7,221 億元、櫃買約 1,654 億元，全市場量比 0.82。今天不是爆量突破，而是 價格強＋廣度強＋產業鏈強，但成交量沒有擴張。

正向解讀是前一日大量賣壓已釋放，供給縮減後不需要非常大量就能推高價格；保守解讀則是仍可能包含 Short Covering 與跌深回補。因此今天可以確認風險偏好重新擴張，但不能直接宣告主升段確認或滿倉追價。

十、操作模式：證據確認，等待結構加碼

市場層級的第一層確認已通過，操作模式可由防守、等待證據，升級為允許重新增加 Exposure；但不能一次全部加回。

今天解決的是「能不能承擔風險」，答案是可以；但尚未回答「現在的價格是不是好的進場點」。Selection Edge 大幅提高，但許多股票單日上漲 5%～10% 後，Entry Edge 反而下降。

所以策略由：

Evidence before Exposure

進入：

Evidence Confirmed → Add on Structure

等待領先股量縮整理、突破 K 棒不被吞噬，或第二拍進場點出現，再按結構分批增加曝險。

十一、下一交易日三種情境

🟢 最佳情境：正常換手

加權約 0%～+1%，甚至小跌都可接受；PCB、記憶體、封裝、ASIC、CPO／CXL 多數維持強勢或量縮整理，市場廣度不快速翻成 -30%～-40%。今天漲、下一日不吐回，才是最漂亮的 Follow-through，可開始尋找第二拍進場。

🟡 中性情境：指數震盪、族群分化

ASIC、Memory、PCB 開始分化，但領先股不破今日大量區、不破突破 K 棒低點，並以量縮方式整理。這代表「全面攻擊」進入「選股」，仍適合依個股結構操作。

🔴 危險情境：強力反彈降級

若加權下跌 1.5% 以上、櫃買下跌 2% 以上，PCB、HBM、ASIC、先進封裝大量出現開高走低、爆量黑 K 或吞噬今日紅 K，且市場廣度重新掉到 -30%～-40%，則 10/28 必須重新降級為強力跌深反彈。

十三、正式市場燈號

🟢 綠燈：Risk-on Confirmation Day／風險偏好重新擴張確認日

最重要的證據不是單一指數漲幅，而是櫃買 +4.1% 收最高、上市廣度 +39.6%、櫃買廣度 +41.9%、尾盤廣度重新擴張，以及 PCB 21/21、ASIC 8/8、Memory 14/14、封裝量測 12/12、CXL 8/8 同時成立。

保留條件是量比只有 0.82，因此綠燈代表允許承擔更多風險，不代表可以忽略價格與進場位置。

十四、執行結論

10/28 已從「Leader 存活」正式進化為「市場跟上 Leader」，並由快速輪動進入主線共振。風險偏好重新擴張已確認，接下來重點不再是能不能買股票，而是哪些第一梯隊個股能在隔日正常換手後，提供值得承擔風險的第二拍進場點。
